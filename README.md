# ENGR 290 Hovercraft

Team hovercraft project for ENGR 290 (Concordia University, Fall 2026).

## Layout

| Folder | What goes here |
| --- | --- |
| `cad/` | Fusion exports for each design (`.f3d` / `.step`), plus drawings |
| `firmware/` | Microcontroller code |
| `docs/` | PDR, reports, calculations, meeting notes |
| `media/` | Photos, renders, test videos |

## Working in this repo

- Pull before you start, and commit small changes with a clear message.
- Work on a branch (`name/what-you-are-doing`) and open a pull request into `main`.
- Fusion files live in the cloud, so export a `.f3d` and a `.step` to `cad/` whenever a design reaches a milestone.
